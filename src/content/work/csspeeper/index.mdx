## My role

In 2016 I have created CSS Peeper Chrome extension to boost designers productivity. Ever wondered what’s the line-height, font or a button size on a website? We provide you the ultimate tool to satisfy your design curiosity.

### Key achievements

- 500,000+ active users in Chrome store
- Featured by top design influencers and magazines
- Featured by Google Chrome store team

## Background

Imagine that you’re working on a redesign of a digital product without a style guide to refer to. Probably the first thing you’d do is to go to the product website to check the design system and brand essence: colors, typography, spacings and look for specific imagery or icons.

When you’re at that point, you probably want to inspect some existing CSS styles, get the color palette or download some assets that might be reused. The question is: **How do you get all of that without digging in a code inspector of a browser?**

After hours of searching I’ve decided to create something new from scratch. The unfulfilled need turned into a side project called [**CSS Peeper**](https://csspeeper.com/). I’ve proposed the design concept to my friend, [Jędrzej Sadowski](https://pl.linkedin.com/in/jedrzejsadowski/en), Front-End Developer with a can-do approach and everything started!

The tool I’ve always missed in my design toolkit was a simple and handy code inspector that will give me all the necessary styles on a silver plate. Driven by these needs I’ve defined a wish list for MVP:

### Features

- Check the styles available on the website
- Typography used on a website (font family, size, line-height, etc.)
- Overview of all colors available on a website
- Download assets (pngs, svgs, jpgs, etc.) within a single click.
- Inspect single element in order to get the measurements, padding and style effects like shadows, hover states etc.

Designing for designers is a really hard thing. We see things that other people don’t, therefore nailing the first impression was a key priority. I believe that beauty in user interfaces is as important as the usability. Today the great visual details differentiate the great products from the mediocre ones. We wanted CSS Peeper to stand out!
