Memory makes an agent more useful, and a bit creepier. In a recent study, most people were unpleasantly surprised when they saw what an assistant remembered about them. If people can see the memory and change it, there's much less to be surprised by.

Don't hide the controls in settings. Put them wherever the memory shows up.
