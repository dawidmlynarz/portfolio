A lot of agent failures go back to the first decision. Either the task shouldn't be handed over at all, or the model can't do it reliably yet. Catching that at kickoff costs twenty minutes.

Answer from what the model can do today, not what you hope it can. If you don't know, write "unknown" and go test it.
