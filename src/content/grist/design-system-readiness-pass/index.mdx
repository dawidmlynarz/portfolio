Each fix this season is small. Together they move a system from "agents improvise around it" to "agents use it properly", and this skill does the groundwork while you make the calls.

Watch for accepting generated "don't use for" lines without checking them. They encode your system's intent, which the skill can only guess.

## Example

The summary reads: _Score 5/10 (tokens 2, APIs 2, access 0, docs 1, guidance 0). Generated: 142 token descriptions (19 marked \[ASK\]), contracts for 10 components, AGENTS.md, DESIGN.md, llms.txt. Estimated new score: 8/10 once reviewed. Not addressed: agent access needs an engineering decision._
