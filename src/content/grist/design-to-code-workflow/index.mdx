This is the season's handoff as one workflow. The brief, the acceptance criteria and the build each have their own skill, and a separate design QA agent reviews the build. That agent didn't write the code, so it doesn't share the builder's idea of what "done" looks like.

I used this shape to rebuild a working AI proof of concept with [Anvil UI](/work/zazmic-anvil-ui), the design system for AI agents I built. [YOU: what the QA step caught that you'd have missed.]
