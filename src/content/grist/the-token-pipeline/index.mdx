I built a small Figma plugin that turns Figma variables straight into a token file Style Dictionary can read. It keeps the links between tokens (a role pointing at a raw colour) and exports text styles too. I needed one specific export: JSON that follows the W3C design tokens format and that Style Dictionary reads as it is. So I built it. It isn't public. From there Style Dictionary builds the code for each platform, and Storybook shows the result.

For agents the important part is that code only ever sees the semantic layer: names that say what a value is for.

## Example

An illustration of a semantic token in the exported file. It points at a raw colour instead of copying its value, and says where it goes:

```json
"link": {
  "$type": "color",
  "$value": "{color.blue.600}",
  "$description": "Links in body text"
}
```
