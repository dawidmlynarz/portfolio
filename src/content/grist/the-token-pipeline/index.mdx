I built a small Figma plugin that exports variables to DTCG JSON. It keeps aliases as references and exports text styles too. [YOU: why you built your own instead of using an existing exporter.] From there Style Dictionary builds the web and React Native outputs, and Storybook shows the result.

For agents the important part is that code only ever sees the semantic layer. [YOU: can the plugin be shared?]

## Example

A semantic token as it comes out of the export, alias kept:

```json
"link": {
  "$type": "color",
  "$value": "{color.blue.600}",
  "$description": "Links in body text"
}
```
