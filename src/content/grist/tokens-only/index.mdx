I want control over the output. I don't want stray styles flying around the codebase.

Without this rule, an agent simply makes styles up on the spot, or hard-codes everything. With it, every colour, space and size comes from the system. When something really needs a custom style, the agent asks, I approve it, and we create a new token if one is needed.
