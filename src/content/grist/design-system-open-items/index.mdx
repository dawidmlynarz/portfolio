When I documented a company website's design system, the most useful page turned out to be the list of what wasn't there yet. No design owner, no accessibility target, buttons drawn as static frames, spacing and radius not tokenised.

Writing it down stopped people, and agents, from treating the gaps as decisions. Each item got an owner, so the list became the system's backlog instead of a complaint.

It also made the build or adopt call easy. We adopted shadcn/ui, an open-source component library, instead of drawing every variant in Figma. It gave us accessible components in code from day one, and the Figma side only had to match them.
