## My current take

Props tell an agent how to use a component. They don’t tell it whether to, which is how a modal ends up where a toast belonged.

Write the purpose, the limits and a “don’t use for” line once, next to the component. The “don’t use for” line does most of the work, and it’s the one people skip.
