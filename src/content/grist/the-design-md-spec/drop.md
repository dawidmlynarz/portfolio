# DESIGN.md

## Rules

- Semantic tokens only. Never hex, rgb or raw px in components.
- Reuse a component before making a new one. Add a variant instead of a near-copy.

## Tokens

Where they live: [path]. Names follow [pattern]. Each one has a description.

## Components

One line each: name, what it's for, when not to use it.

- Button: actions. Not for navigation; use Link.

## Check before done

- Light and dark theme
- Keyboard focus visible
- 375, 768 and 1440 wide
