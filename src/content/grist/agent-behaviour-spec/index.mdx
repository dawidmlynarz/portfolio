Most agents behave the way their system prompt says, and nobody designed the system prompt. With a spec, behaviour gets decided and reviewed like any other design work, and the prompt is written from it.

"Be careful with payments" is a hope. Write each boundary so a test could catch it being broken.

## Example

The _Checkpoints_ section for a group-travel agent: _Asks before: paying, cancelling a booking, emailing anyone outside the team. Acts and reports: searching, holding seats for up to 24 hours, drafting messages. Silence on a checkpoint means nothing happens._
