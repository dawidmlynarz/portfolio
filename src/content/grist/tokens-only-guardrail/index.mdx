I want control over the output. I don't want stray styles flying around the codebase.

So I give it a guardrail, a rule it reads before writing any code. Without one, agents make styles up on the spot or hard-code everything. With it, colours, spacing and sizes all come from the system. When something really does need a custom style, the agent asks me first, and if I agree we add a token.
