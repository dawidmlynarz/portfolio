I want control over the output. I don't want stray styles flying around the codebase.

This is a guardrail: a standing rule the AI reads before it writes any code. Without it, an agent simply makes styles up on the spot, or hard-codes everything. With it, every colour, space and size comes from the system. When something really needs a custom style, the agent asks, I approve it, and we create a new token if one is needed.
