Show what stops it before it starts. If an agent can spend money or run for an hour, the person should see the cap up front, in their own units: euros, minutes, emails sent. A limit buried in settings doesn’t count.

When the agent gets close to a limit it should say so and ask. Quietly stopping halfway leaves people with half a job and no idea why.
