An agent's copy ends up everywhere. Some is in the system prompt, some in the first-run message, the errors, the approval screens, the memory notices. The skill pulls it into one list, rewrites it in one voice and checks it against this season's rules.

Read the copy on the screen before you approve it. Lines that look fine in a doc can fall apart on a phone.

## Example

The inventory finds 41 strings: 6 contradict the voice card (two apologise twice, four promise "instantly"), 3 explanations name no inputs, and the memory notice never says how to delete a memory. Each comes back with a rewrite.
