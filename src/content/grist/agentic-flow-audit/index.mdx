This is the season in one tool. Every earlier drop is a check in this audit: does the agent show its plan, stop where it should, say why, let people undo, and hand over cleanly?

I wrote it as a skill so it runs the same way every time, and so the report comes back in the same shape for every flow.

## Example

Part of a report for an email assistant that sends follow-ups:

```markdown
1. Checkpoints (high): sends on the person's behalf with no pause. Add a checkpoint before any send.
2. Undo (medium): sent emails can't be recalled. Add a 30-second send delay with Undo.
3. Plan (ok): shows the list of follow-ups before it starts.
```
