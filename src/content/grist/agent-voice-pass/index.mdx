Agent copy is scattered: system prompt, first-run message, explanations, errors, approvals, memory notices. This skill gathers it in one place, writes it in one voice, and checks it against this season's rules.

Watch for approving copy in a document. Read it in context; a line that works in a list can fail on a small screen.

## Example

The inventory finds 41 strings: 6 contradict the voice card (two apologise twice, four promise "instantly"), 3 explanations name no inputs, and the memory notice never says how to delete a memory. Each comes back with a rewrite.
