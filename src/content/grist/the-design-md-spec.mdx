## My current take

Agents read what’s in the repo. If your rules live in Figma comments and a wiki page, the agent never sees them.

So keep one short file next to the code. A design.md that says “semantic tokens only, never hex” and lists each component in a line does more for an agent than a big docs site it can’t reach.
