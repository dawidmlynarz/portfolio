It was actually a synthetic sprint, run by an agent as if it was a real activity. It went from an audit of competing assistants to a journey map, an interaction spec and a clickable prototype with a scripted main flow.

The effort was lots of human input to make it work, since the agent can't assume too much. So the loot starts with a guardrail. The agent doesn't assume, and when it lacks context it always asks.

## Example

An illustration of one stage in the interaction spec, for a hotel booking assistant:

- **Stage:** choosing dates
- **Says:** "Which nights are you looking at? I can show what's free around them too."
- **Shows:** a date picker and three nearby date options with prices
- **Does:** holds nothing until the person picks a room
- **Never:** books, or charges, without a final confirmation
