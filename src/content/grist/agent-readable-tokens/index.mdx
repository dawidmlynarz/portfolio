Name tokens by job and describe each one. An agent reading `blue-500` has to guess what it’s for. An agent reading `color-text-link`, with one line saying where it goes, mostly doesn’t.

The description is what the agent falls back on when two names look alike. It’s also the field most token files leave empty.
