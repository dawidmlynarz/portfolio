{/* CLAUDE: turned from a rule into a lint prompt at Dawid's request (2 Nov). Title, summary, steps and loot are Claude's. The Why below is unchanged. Confirm or rewrite. */}

Other designers have been flagging this one online. An agent picks the wrong token when all it has is a name. Reading `blue-500`, it has to guess what the colour is for. Reading `color-text-link`, with a line saying it's for links in running text, it mostly doesn't.

So every semantic token gets its purpose written down. Primitives like `blue-500` don't need one, because components shouldn't use them anyway.
