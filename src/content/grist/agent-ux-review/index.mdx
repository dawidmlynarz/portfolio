This season's drops, run in order, are a design review. Packaged as a skill, an AI tool can run the whole review from a brief and you spend your time on the judgement calls.

Watch for a review run on a vague brief. If the actions list is missing, the skill will ask for it. Don't let it guess.

## Example

For a ticket-buying assistant, the report's verdict reads: _Build discovery as an assistant; let the agent act only to hold seats. Purchases stay with the person._ Issue 1 is the purchase buried in a four-step plan (severity high), fixed with a separate checkpoint.
