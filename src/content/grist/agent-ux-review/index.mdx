Run this season's drops in order and you've done a design review. As a skill, your AI tool runs the whole thing from a brief, and you spend your time on the calls that need judgement.

A vague brief gets a vague review. If there's no list of actions, the skill asks for one, so give it one instead of letting it guess.

## Example

For a restaurant booking assistant, the report's verdict reads _Build discovery as an assistant, and let the agent act only to hold a table. Paying the deposit stays with the person._ Issue 1 is the deposit buried in a four-step plan (severity high), fixed with a separate checkpoint.
