Agent ideas usually come from the feature list, or from wherever AI is easiest to bolt on. I start from a journey map instead. Map the stages and mark where it hurts at each one, like where people drop off, slow down, get it wrong or ask for help. The good places for an agent tend to show up by themselves.

Often the biggest pain point is earlier in the journey than anyone expected. On one project it sat well before the step everyone assumed needed help, so starting there would have polished the part that was already working.
