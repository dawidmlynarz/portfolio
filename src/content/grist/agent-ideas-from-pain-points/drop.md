When looking for agent or AI opportunities in a product, start from the user journey, not the feature list. Map the stages, then mark the pain points at each one: where people drop off, slow down, make mistakes or ask for help, using the evidence available. Propose agent ideas only for the biggest pain points, and name the evidence each one rests on. Don't start from where AI is easiest to add.
